# GreyLog v0.1.0

Initial local-first open-source release for Windows and Linux.

- Tail local log files or ingest JSON events through the authenticated loopback API and CLI.
- Normalize common PostgreSQL, MySQL, MongoDB, SQL Server, Redis, Oracle, syslog, and JSON formats.
- Evaluate configurable authentication, source-error, and slow-query alert rules.
- View live event volume, source health, alerts, and events in the dark-green analyst dashboard.
- Export retained events and alerts as JSON Lines from the dashboard or to a selected directory with the CLI.

Python 3.11 or newer is required. See the [README](../README.md) for setup, supported parser scope, retention, and security limits. GreyLog is Apache-2.0 licensed; the GreyNOC owl asset is included under that license.
